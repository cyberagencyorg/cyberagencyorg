# Profile imagery

The current header and marks are web-sized derivatives of the user-supplied Cyber Agency identity assets. Their geometry and language have not been redrawn or regenerated.

- `cyber-agency-banner.webp`: published GitHub header derived from `cyber-agency-banner.png`.
- `cyber-agency-mark.webp`: derivative of `cyber-agency-logo-mark.png`.
- `cyber-agency-lockup.webp`: derivative of `cyberagency-logo-primary-combo-dark.png`.

The source standard, hashes, and governance records are maintained in the private `cyberagencyorg/ca-brand` repository. The previous generated `profile-dark.svg` and `profile-light.svg` are retired and removed from the active profile.

Do not invent replacement marks, claims, charts, or decorative text to fill this page. A GitHub README is a front door, not an exhaustive services brochure.
